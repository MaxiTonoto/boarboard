# BOARBOARD🐗📔
## TO-DO APP con Kanban Board & Dashboard.

### Tecnologías:
 - Django + Django Rest Framework.
 - Bun: React con Vite y SWC.
 
### Arquitectura y diseño:
 - MTV (Django) con separación de frontend y backend.

### Comandos útiles:
 - Clonar 
 `git clone https://github.com/MaxiTonoto/boarboard`
 
 - Crear venv: `python -m venv .venv`
 - Instalar dependencias: `pip install -r requirements.txt`

 - Instalar módulos Bun: `bun install`
 
 - Servidor de prueba backend: `python manage.py runserver`
 - Servidor de prueba backend frontend: `bun run dev`
